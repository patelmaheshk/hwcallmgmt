Template Variables Guide (click to expand)
Use these in your EmailJS template: {{to_email}} — recipient's email (caller or admin)
{{to_name}} — recipient name
{{caller_name}} — caller's full name
{{caller_email}} — caller's email address
{{ticket_id}} — e.g. HW-4821
{{email_type}} — Ticket Submitted / Status Updated / Ticket Closed
{{priority}} — P1 / P2 / P3 / P4
{{status}} — Open / In Progress / Closed…
{{device}} — device type
{{department}} — department
{{institution}} — institution
{{technician}} — assigned tech
{{description}} — issue description
{{resolution}} — resolution notes
{{created_date}} — submission date/time
